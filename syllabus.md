# Программа курса «История и философия науки»

Аспирантский курс, подготовка к кандидатскому экзамену по истории и
философии науки. Годовой: осенний (занятия 01–13) и весенний (занятия
14–26) семестры. **26 занятий = 26 экзаменационных вопросов**, каждое
занятие полностью раскрывает один вопрос.

Форма контроля: итоговый кандидатский экзамен; в течение года —
семинары (доклады по вопросам) и рефераты по истории отрасли науки.

## Принципы курса

- Каждый вопрос раскрывается **полностью**, по пунктам формулировки.
- Прямые цитаты — только из корпуса публичного достояния, с координатами
  «файл · фрагмент #N»; проверка автоматическая (`make verify`).
- Охраняемые авторы (Поппер, Кун, Лакатос, Фейерабенд, Витгенштейн,
  Рассел и др.) — авторский синтез с пометкой «вне корпуса».
- Рекомендуемая доп. литература современная (охраняемая) приводится в
  занятиях как список для чтения (не цитируется).

## Как работать с курсом

Каждое занятие — отдельный файл в [`lectures/`](lectures/) и полностью
раскрывает один экзаменационный вопрос: тезис, источники и свидетельства
из корпуса, авторский синтез, вопросы для самопроверки и задания.

| Шаг | Команда | Что даёт |
|---|---|---|
| Материал занятия | `make session n=17` | Полный текст занятия с цитатами и координатами |
| Вопросы и задания | `make assignment n=17` | Только вопросы и задания |
| Поиск по корпусу | `make search QUERY="парадигма"` | Фрагменты с координатами «файл · фрагмент #N» |
| Проверка цитат | `make verify` | Сверка каждой цитаты с корпусом |
| Состояние курса | `make status` | Готовность занятий и корпуса |
| Инструменты | `make help` | Все доступные цели |

Полный разбор рабочего процесса — [`docs/AGENT-WORKFLOW.md`](docs/AGENT-WORKFLOW.md).

### О координатах цитат

Контракт курса требует координату «файл · фрагмент #N» для каждой прямой
цитаты. Часть координат была утеряна при вставке цитат и восстановлена из
[`verification/REPORT.md`](verification/REPORT.md). Там, где отчёт номера
не даёт, координата помечена «номер требует сверки» — номер не выдуман.
Пометка снимается после прогона `make verify` с локальным корпусом.
