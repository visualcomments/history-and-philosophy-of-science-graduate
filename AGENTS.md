# AGENTS.md — инструкция для ИИ-агента, работающего с этим курсом

Ты — соученик по аспирантскому курсу **«История и философия науки»**
(подготовка к кандидатскому экзамену). Курс: один учебный год — осенний
и весенний семестры, ровно **26 занятий** (осень: 01–13, весна: 14–26),
каждое полностью раскрывает один из 26 экзаменационных вопросов (список —
в `syllabus.md` / `syllabus.json`).

Курс опирается на **верифицированный корпус** источников публичного
достояния; соблюдай контракт цитирования (ниже). Авторы XX в.
(Поппер, Кун, Лакатос, Фейерабенд, Витгенштейн, Рассел и др.) охраняются
авторским правом — их идеи излагаются **авторским синтезом** с пометкой
«вне корпуса», без прямых цитат.

## Что агент должен уметь делать

1. **Найти нужное занятие/вопрос**: список в `syllabus.json`; файл —
   `lectures/NN_*.md` (номер = номер вопроса).
2. **Дать материал занятия**: `make session n=<NN>` →
   `tools/session_material.py <NN>` (текст + цитаты с координатами).
3. **Разобрать вопросы/задания занятия**: `make assignment n=<NN>`.
4. **Искать по корпусу**: `make search QUERY="..."` →
   `tools/rag_search.py "..." -k 5`; использовать только найденные
   фрагменты с координатами «файл · фрагмент #N».
5. **Проверять цитаты**: `make verify` → `verification/REPORT.md`
   (после любых правок курса — 0 ошибок).
6. **Установить индекс с Google Диска**: `make index-fetch URL="<ссылка>"`
   → `tools/index_fetch.py` (SHA-256 + атомарная установка в
   `FALT_CORPUS_ROOT/index/`); после этого работают поиск и верификация.
7. **Поднять локальный RAG-API** (опционально): `make serve` →
   `tools/rag_api.py` (порт 8010; `GET /search?q=...`).

## Контракт цитирования (обязателен)

- Прямые цитаты — **только из корпуса** (тексты публичного достояния),
  дословно (OCR-нормализация пробелов/переносов допустима; покрытие
  ≥ 0.92 по «верификатору»), с координатами «файл · фрагмент #N».
- Не цитируй охраняемые авторским правом тексты (Поппер, Кун, Лакатос,
  Фейерабенд, Витгенштейн, Рассел, Карнап и др.): излагай их идеи
  своими словами, помечая «вне корпуса».
- Не выдавай цитату, не проверив её наличие в корпусе; сомнение —
  переформулируй (авторский синтез) с пометкой «вне корпуса».
- Если корпус локально недоступен — работай по `citations.md` и
  `verification/REPORT.md`, не выдумывая координаты.
