# Инструменты веб-поиска и сбора корпуса

Рекомендованный стек выбран по обзору Vellum «Best Web Search APIs and MCPs for AI Agents in 2026»:

- **Exa MCP** — семантический поиск и чтение страниц, особенно полезен для академических и технических источников.
- **Firecrawl MCP** — полнотекстовое извлечение, PDF/OCR, очистка HTML и последующее сохранение документов.
- **OpenAlex API** — основной каталог научных работ и лицензий.
- **Internet Archive** — первоисточники в общественном достоянии.
- **Crossref** — дополнительная проверка DOI и лицензии издателя.

## Конфигурация OpenCode

Серверы устанавливаются глобально, без ключей в репозитории:

```text
opencode mcp add exa --global --url https://mcp.exa.ai/mcp
opencode mcp add firecrawl --global --url https://mcp.firecrawl.dev/v2/mcp-oauth
opencode mcp list
```

Exa подключён и работает в режиме keyless. Firecrawl добавлен, но требует интерактивной OAuth-аутентификации; её нельзя выполнять в автоматическом скрипте или сохранять секрет в Git.

При необходимости использовать API-ключи, задайте их только в окружении:

```text
EXA_API_KEY=<локально>
FIRECRAWL_API_KEY=<локально>
```

## Политика отбора

1. Искать источники по каждой теме курса через OpenAlex и Exa.
2. Для научной статьи принимать только запись OpenAlex с `is_oa=true`, явной лицензией `cc-by`, `cc-by-sa`, `cc0` или эквивалентной записью издателя/Crossref.
3. Для исторического текста принимать только издание с подтверждённым общественным достоянием и свободным доступом.
4. Firecrawl применять для извлечения текста, но не считать факт доступности доказательством лицензии.
5. Хранить URL, OpenAlex/IA identifier, издателя, лицензию, дату загрузки и SHA-256.
6. Не добавлять прямые цитаты в лекции до пересборки индекса и `make verify`.
