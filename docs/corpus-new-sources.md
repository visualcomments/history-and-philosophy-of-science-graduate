## 3. Научные статьи под свободными лицензиями (`oa__*`) — 15 файлов

Открытый доступ (DOAJ). Лицензия проверяется на уровне записи **журнала**
(в записи статьи DOAJ поле `license` пустое) и подтверждается через Crossref
по DOI. Манифест — `catalog/doaj_philosophy_admitted.json`.

**Важно о качестве отбора.** Массовый поиск DOAJ дал 45 статей, из которых
30 отброшены как нерелевантные (преподавание, религиоведение, медицина,
рецензии, отозванная статья). Оставлены 15, реально относящихся к темам
курса: эпистемология Куна и Поппера, фальсификационизм и проблема индукции,
научные революции, научный реализм, причинность, философия физики.
Фильтр — `scripts/filter_oa_relevance.py`.

Лицензии: CC BY, CC BY-SA, CC BY-NC, CC BY-ND, CC BY-NC-ND, CC BY-NC-SA.
Лицензии с NC/ND ограничивают коммерческое использование и производные
произведения — для учебного корпуса допустимо, но при публикации корпуса
ограничение должно быть указано.

## Воспроизведение

```bash
python scripts/ia_philosophy_search.py            # поиск PD-первоисточников
python scripts/ia_download.py --prefix philosophy__ --txt-dir <корпус>/txt --identifiers ...
python scripts/fetch_doaj_philosophy.py --txt-dir <корпус>/txt --max 45
python scripts/filter_oa_relevance.py --txt-dir <корпус>/txt
python scripts/wiki_dl_topics.py --txt-area <корпус>/txt --topics "..."
```
