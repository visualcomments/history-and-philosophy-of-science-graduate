# История и философия науки (аспирантский курс)

Открытый учебный курс **«История и философия науки»** для аспирантов
первого года обучения: подготовка к **кандидатскому экзамену** по
истории и философии науки. Длительность — один учебный год (осенний
и весенний семестры), ровно **26 занятий** (13 + 13), каждое полностью
раскрывает **один** из 26 экзаменационных вопросов.

Курс построен по образцу курса «История России: история и философия
науки и технологий»:
- верифицированный корпус источников (публичное достояние); цитаты — только
  с координатами «файл · фрагмент #N»;
- RAG-индекс, распространяемый через **Google Диск** (архив + манифест с
  SHA-256, инструмент `make index-fetch`);
- репозиторий адаптирован под ИИ-агента ([botai](https://github.com/visualcomments/botai)).

Все оригинальные материалы распространяются по лицензии **GNU GPL v3**.

## Что в репозитории

| Раздел | Содержание |
|---|---|
| `syllabus.md`, `syllabus.json` | Программа курса + машиночитаемая версия |
| `lectures/` | 26 занятий `NN_*.md` — полное раскрытие вопроса, цитаты, вопросы, задания |
| `citations.md` | Правила цитирования и карта «вопрос → источники» |
| `PROVENANCE.md` | Происхождение и **лицензии** всех текстов корпуса (PD + статьи CC BY-SA 4.0) |
| `verification/REPORT.md` | Автоматическая проверка каждой цитаты курса |
| `agents/` | Трек и шаблон прогресса (конвенция botai) |
| `tools/` | Поиск, загрузка индекса с Google Диска, верификация, материалы и задания занятия, локальный RAG-API |
| `Makefile` | Короткие цели (`make help`) |
| `docs/` | `AGENT-WORKFLOW.md`, `GOOGLE-DRIVE.md`, `CORPUS.md` |

## Быстрый старт

```bash
make help                        # список целей
make session n=10                # материал занятия 10 (Кант)
make assignment n=10             # вопросы и задания занятия 10
make index-fetch URL="<ссылка>"  # установить RAG-индекс с Google Диска
make search QUERY="фальсификационизм"
make verify                      # проверка цитат (0 ошибок — норма)
```

## Лицензии и источники

Корпус состоит из текстов публичного достояния (классика философии и
науки: Аристотель, Бэкон, Декарт, Локк, Беркли, Юм, Кант, Конт, Милль,
Спенсер, Мах, Пуанкаре, Джеймс, Лаплас и др.). Авторы XX в. (Поппер,
Кун, Лакатос, Фейерабенд, Витгенштейн, Рассел и др.) цитируются только
на уровне авторского синтеза с пометкой «вне корпуса» (их тексты
охраняются авторским правом). Подробности — `CORPUS.md`, `citations.md`.
